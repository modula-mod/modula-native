# MOL-03R — UI & 3D Defect Matrix

| ID | Severity | Surface | Defect Observed | Root Cause | Fix Implemented | Status |
|---|---|---|---|---|---|---|
| **D-01** | **P0** | Studio 3D Stage | Pebble appeared enclosed in a see-through / faceted dome in Studio when a background scene was active | `bg.*` items in `moliboo_wardrobe_fits.json` used `rotationDegrees: [90, 0, 0]`, placing the `Item_bg_*_part01` backdrop dome shell over the front of the character instead of behind it | Rotated all `bg.*` and `slot:background` fits to `[90, 0, 180]` across all 10 Originals so backdrop domes open toward the camera behind the character; verified via `MOL03WardrobeFitValidationTests` | **FIXED** |
| **D-02** | **P0** | Studio 3D Stage | Random unrequested items (scarf, bandana, floating aura, face bandage) appeared on Pebble on first Studio open | `MascotWardrobeStore.applyOutfitOfTheDayIfNeeded()` silently mutated an empty outfit with random `.hat`, `.accessory`, and `.aura` items on `onAppear` | Disabled automatic OOTD mutation when `MolibooFeatureFlags.native3DEnabled` is active so characters open in their clean canonical state or explicit user-saved outfit | **FIXED** |
| **D-03** | **P0** | Studio 3D Wardrobe | Pebble hats (`hat.*`), glasses (`face.*`), and body wraps (`top.*`, `out.*`, `bot.*`, `acc.*`) floated off-center or clipped into Pebble's wider `0.176 × 0.120 m` body | Pebble's `anchor_head` is at `x = +0.04 m` (tilted crown) and its body is wider than standard `e070055` rings | Applied solved per-item offsets (`x = -0.04` for centered hats, flush surface offsets for `face.*`) and added per-axis `stretch: [sx, sy, sz]` in `MolibooWardrobeFit` (`MolibooWardrobeRig`) so body garments hug Pebble without clipping | **FIXED** |
| **D-04** | **P0** | Studio Sheets | Opening `Expressions`, `Play`, or `Wardrobe` covered too much of the 3D stage or allowed `.large` full-screen sheets to hide the character | `.wardrobe` / `.more` used `[.medium, .large]` and `.expressions` / `.play` used `.height(300)` | Set compact `.height(250)` default detent for `Expressions` and `Play`, `.height(300)` for `Style`, and capped expanded detent at `.fraction(0.76)` for `Wardrobe` / `More` with `.presentationBackgroundInteraction(.enabled(upThrough: .fraction(0.76)))` | **FIXED** |
| **D-05** | **P1** | Collection Screen | Collection used a cramped adaptive 3/4-column grid without search, filters, or personality copy | `MolibooCollectionView` used `GridItem(.adaptive(minimum: 100))` with only name and `#` | Redesigned `MolibooCollectionView` into a responsive 2-column grid with search (`searchable`), filter chips (`All`, `3D Ready`, `Unlocked`, `Coming Later`), 128pt portrait stage, `#001` monospaced badge, and 2-line personality descriptor | **FIXED** |
| **D-06** | **P1** | Settings Hub & Wardrobe | `MolibooSettingsView` character cards used 9pt/8pt text and Wardrobe showed `"1 items"` and truncated `"Moliboo Signat..."` | Hardcoded `.font(.system(size: 9))` and 1-line 92pt wardrobe tiles | Upgraded Hub character cards to readable `.footnote` / `.caption2` with explicit dark-on-pastel contrast and `3D` badge; widened Wardrobe tiles to `102pt` with 2-line titles and fixed singular/plural item count | **FIXED** |
| **D-07** | **P1** | Safe Areas & Scrolling | Bottom rows in Collection, Settings Hub, Wardrobe, and Card Binder could sit near or under bottom overlays/tab bar | Missing explicit scroll content bottom margins on several `ScrollView`s | Added `.contentMargins(.bottom, 96, for: .scrollContent)` on Collection & Settings Hub, `84pt` on Card Binder, and `28pt` + `36pt` padding on Wardrobe grid | **FIXED** |
| **D-08** | **P1** | Collectible Cards | Card outer glow was overly heavy (`radius: 24`) and holo foil ignored live CoreMotion / drag `tilt` | `molibooHoloFoil` modifier passed `.float2(0, 0)` for tilt and moves box had low-contrast `0.08` white fill | Wired live `tilt` (`CGSize`) into `molibooHoloFoil`, added `molibooShimmer` for Rare/Epic/Legendary, toned down glow radius (`[3, 7, 11, 16]`), and darkened moves panel (`black.opacity(0.34)`) for crisp WCAG readability | **FIXED** |
